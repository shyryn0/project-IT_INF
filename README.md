# Лабораторная работа №4 — вариант 8

**Тема:** Автоматизированная инвентаризация и мониторинг рабочей станции на Python  
**Группа:** ПТ 16:30  
**Вариант:** 8

## Состав проекта

- `inventory.py` — собирает сведения об ОС, процессоре, оперативной памяти, дисках и сетевых интерфейсах; выполняет анализ и сохраняет паспорт в JSON.
- `monitor.py` — измеряет загрузку CPU, RAM и диска, проверяет пороговые значения, записывает результаты в CSV и выводит статистику.
- `requirements.txt` — необходимые Python-библиотеки.

## Параметры варианта 8

- Интервал измерений: 3 секунды.
- Количество измерений: 20.
- Пороги: CPU — 90%, RAM — 80%, DISK — 80%.
- Дополнительная метрика: текущая частота CPU в МГц.

## Установка на macOS

Откройте Terminal в папке проекта и выполните:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Запуск инвентаризации

```bash
python3 inventory.py
```

После запуска создаётся файл `passport_<имя-компьютера>.json`.

## Запуск мониторинга

```bash
python3 monitor.py
```

Мониторинг выполняет 20 измерений с интервалом 3 секунды. После завершения создаётся `monitor_log.csv` и выводится среднее, максимальное и минимальное значение метрик.

## Проверка результата

Откройте созданные JSON- и CSV-файлы в VS Code. Фактические результаты зависят от компьютера и нагрузки в момент запуска.

## Примечание

На некоторых моделях Mac или версиях macOS `psutil.cpu_freq()` может не возвращать частоту CPU. В таком случае программа показывает `н/д`, не завершая работу с ошибкой.
